04Sistema gestor de bases de dades

Tipus de SGBD

Sage 200 treballa exclusivament amb Microsoft SQL Server, un SGBD relacional: les dades s'organitzen en taules amb files i columnes, relacionades entre elles per claus primàries i foranes, i es consulten amb el llenguatge SQL (en el dialecte de Microsoft, T-SQL).

En instal·lacions petites es pot fer servir l'edició gratuïta SQL Server Express (limitada en mida de base de dades i memòria), mentre que en empreses mitjanes s'usa SQL Server Standard. En la modalitat al núvol, la base de dades s'allotja a Azure.

Altres informacions rellevants

  • Integritat: com que tots els mòduls comparteixen la mateixa base de dades, una dada s'introdueix una sola vegada i la resta de mòduls la reutilitzen.
  • Còpies de seguretat: en local es fan amb les eines de SQL Server o des de la mateixa aplicació; al núvol les gestiona la plataforma.
  • Accés extern: eines de BI com Power BI o Excel poden llegir les dades a través de connectors ODBC/ADO.NET.
  • Bona pràctica: no s'ha d'escriure directament a les taules de Sage des de fora de l'aplicació, perquè es poden saltar regles de negoci (comptabilització, estocs…). Les modificacions es fan amb les eines oficials.

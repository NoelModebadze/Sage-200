05Instal·lació i accés al sistema

Tipus d'instal·ladors

  • Instal·lador de servidor (executable per a Windows): instal·la els components centrals i crea o connecta la instància de SQL Server.
  • Instal·lador de client / estació de treball: s'executa a cada ordinador d'usuari i apunta al servidor.
  • LiveUpdate: servei d'actualització automàtica que descarrega i aplica noves versions i canvis legals.
  • Modalitat al núvol: no hi ha instal·lador per a l'usuari; l'aprovisionament a Azure es fa de manera desatesa.

Procés d'instal·lació o contractació

  1. Anàlisi amb un partner. Un distribuïdor autoritzat estudia els processos de l'empresa i proposa l'edició, els mòduls i el nombre d'usuaris.
  2. Contractació. Es signa la llicència (compra o subscripció) o es contracta en línia la modalitat al núvol.
  3. Preparar el servidor. Windows Server compatible, .NET Framework 4.8 i una instància de SQL Server.
  4. Instal·lar servidor i clients. S'executa l'instal·lador al servidor i després a cada estació de treball.
  5. Activar la llicència i crear l'empresa. S'introdueixen les dades de l'empresa, el pla comptable i els exercicis.
  6. Migració de dades. Es carreguen clients, proveïdors, articles i saldos inicials (sovint des de Sage Murano o un altre programa).
  7. Formació i posada en marxa. Es formen els usuaris i es configuren els permisos de cada perfil.

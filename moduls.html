    06Mòduls i funcionalitats

    Sage 200 és modular. Aquests són els tres mòduls més importants i més utilitzats:

    Comptabilitat i finances

    • Llibre diari, balanços i compte de resultats.
    • Tresoreria, cartera d'efectes i remeses SEPA.
    • Connexió bancària i conciliació automàtica.
    • Models d'impostos (IVA, retencions) i SII.
    • Comptabilitat analítica i pressupostària.

    Gestió comercial i magatzem

    • Circuit de vendes: oferta → comanda → albarà → factura.
    • Circuit de compres a proveïdors.
    • Estocs, inventaris, lots i números de sèrie.
    • Tarifes, descomptes i comissions.
    • Facturació electrònica, certificat VERI*FACTU (Llei Antifrau).

    Laboral (nòmines i RRHH)

    • Càlcul de nòmines segons conveni.
    • Seguretat Social: cotitzacions i sistema RED.
    • IRPF i models 111 i 190.
    • Gestió de contractes, vacances i absències.
    • Portal de l'empleat (amb Sage HR).

    Altres mòduls opcionals que llista Sage: CRM amb IA, producció bàsica i avançada, projectes, postvenda, TPV, EDI, Business Intelligence amb IA i l'app mòbil amb Sage Copilot, un assistent per veu. A més, el Marketplace de Sage ofereix més d'un centenar d'aplicacions connectades.

    Capacitat de crear nous mòduls

    Sage 200 és molt personalitzable, i una bona part de la feina dels partners consisteix a adaptar-lo a cada client. Hi ha dos nivells:

    1. Eines de personalització integrades: dins la mateixa aplicació es poden crear camps nous, pantalles, llistats i processos. S'hi programa amb les instruccions de càlcul pròpies de Sage (un llenguatge de script orientat a esdeveniments) combinades amb consultes SQL. Sage ofereix cursos específics (bàsic i avançat) per aprendre-ho.
    2. Desenvolupament extern en .NET: aplicacions i integracions en C# o VB.NET que llegeixen o envien dades a Sage 200 mitjançant la base de dades, connectors o API.

    Llenguatges per crear nous mòduls

    Eines de desenvolupament (IDE)

    • Editor de personalitzacions de Sage 200: integrat a l'aplicació.
    • SQL Server Management Studio (SSMS): per explorar la base de dades i provar consultes.
    • Visual Studio: per a desenvolupaments en C#/VB.NET.
    • Visual Studio Code: per a scripts, portals web i integracions lleugeres.

    Exemples de codi

    1. Consulta T-SQL: els 10 clients que més han comprat aquest any (per a un llistat personalitzat).

    SELECT TOP 10
       c.CodigoCliente,
       c.RazonSocial,
       SUM(p.ImporteLiquido) AS TotalComprat
FROM   Clientes c
JOIN   CabeceraPedidoCliente p
       ON  p.CodigoEmpresa = c.CodigoEmpresa
       AND p.CodigoCliente = c.CodigoCliente
WHERE  c.CodigoEmpresa = 1
  AND  p.EjercicioPedido = YEAR(GETDATE())
GROUP BY c.CodigoCliente, c.RazonSocial
ORDER BY TotalComprat DESC;

    2. C# (.NET): una integració que llegeix clients de Sage 200 per sincronitzar-los amb una botiga en línia.

    using Microsoft.Data.SqlClient;

var cadena = "Server=SERVIDOR\\SAGE200;Database=Sage200;Integrated Security=true;TrustServerCertificate=true";

using var con = new SqlConnection(cadena);
con.Open();

var sql = "SELECT CodigoCliente, RazonSocial, Municipio FROM Clientes WHERE CodigoEmpresa = @emp";
using var cmd = new SqlCommand(sql, con);
cmd.Parameters.AddWithValue("@emp", 1);

using var lector = cmd.ExecuteReader();
while (lector.Read())
{
    // Aquí s'enviaria cada client a l'API de la botiga en línia
    Console.WriteLine($"{lector["CodigoCliente"]} - {lector["RazonSocial"]} ({lector["Municipio"]})");
}

    Exemples il·lustratius amb finalitat didàctica. Els noms exactes de taules i camps poden variar segons la versió; per escriure dades cal fer servir les eines oficials de Sage, no inserir directament a les taules.
